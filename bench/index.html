Sift CPU benchmark

One self-contained Python file. Open it, select all, paste into a file on the target machine. Pure ASCII, so it survives any clipboard.

bench.py.txt

Needs only onnxruntime and numpy, both prebuilt wheels — no C++ compiler, which is what rules out llama-cpp-python. The byte-level BPE tokenizer is included and uses the standard library alone.

python bench.py preflight   # does your package index have what is needed?
python bench.py fetch       # download the model over plain HTTPS (~810 MB)
python bench.py decode      # decode tok/s, with KV cache reuse
python bench.py prefill     # prefill tok/s across context lengths
python bench.py verify      # compare the tokenizer against `tokenizers`, if installed

Use model_q4, the default. Natively q8 measured 20x slower — the reverse of the browser, where the two tied.
