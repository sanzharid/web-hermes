# Working preferences

Commit and push directly to the default branch. Do not create a feature branch
and do not open a pull request unless I ask for one. I can revert a commit if it
turns out to be wrong.

Never subscribe to pull request activity and never schedule check-ins for pull
requests. If I do ask for a PR, open it, give me the link, and stop there.

Nothing gates a push to the default branch, so the local checks are the only
safety net. Run this project's own tests and linters for any change that touches
code, and say in your reply what you ran and what came back. If something fails
and you cannot fix it, push nothing and tell me.
